# 🎵 Winamp ESP32 Radio

Интернет-радио на ESP32 с интерфейсом в стиле классического Winamp.

## Возможности

- 🎛️ **Спектроанализатор** — 24 столбика с пик-маркерами, градиент зелёный → жёлтый → оранжевый → красный
- 📜 **Бегущая строка** — название трека/станции с плавной прокруткой
- 📡 **8 радиостанций** — Europa Plus, DFM, Наше Радио, Дорожное, Маяк, Шансон, Ретро FM, Maximum
- 🕐 **Часы по NTP** — синхронизация времени при подключении к WiFi
- 📶 **Индикатор WiFi** — уровень сигнала и статус подключения
- 🔊 **Регулятор громкости** — цветная шкала с ползунком
- 🎨 **Winamp-эстетика** — металлические панели, зелёный LCD, оранжевый логотип

## Железо

| Компонент | Модель |
|-----------|--------|
| Контроллер | ESP32 (любой вариант) |
| Дисплей | ILI9341 2.4" 320×240 SPI |
| Энкодер | KY-040 (или аналогичный) |
| Звук | Внутренний DAC ESP32 (GPIO25/26) |
| Питание | USB 5V / аккумулятор 3.7V |

## Библиотеки

- [Audio](https://github.com/schreibfaul1/ESP32-Audio) — декодирование MP3-потока
- [LovyanGFX](https://github.com/lovyan03/LovyanGFX) — быстрая отрисовка на ILI9341
- WiFi (встроенная) — подключение к сети
- time (встроенная) — синхронизация NTP

## Управление

| Кнопка/команда | Действие |
|----------------|----------|
| Энкодер ↻ | Громкость вверх / следующая станция (на максимуме) |
| Энкодер ↺ | Громкость вниз / предыдущая станция (на минимуме) |
| Serial `1` | Следующая станция |
| Serial `2` | Предыдущая станция |
| Serial `Space` | Play / Stop |
| Serial `+` | Громкость +1 |
| Serial `-` | Громкость -1 |

> ⚠️ **Known Issue:** логика энкодера (громкость → переключение станций) требует доработки — иногда срабатывает некорректно. Serial-команды работают стабильно.

## Подключение

См. [wiring.md](wiring.md) — подробная схема подключения всех компонентов.

## Оптимизации

- **Инкрементальная отрисовка спектра** — перерисовка только изменившихся пикселей
- **Кэширование LCD** — бегущая строка обновляется только при изменении текста
- `WiFi.setSleep(false)` — отключение power-save для стабильности потока
- Громкость 16/21 — снижение клиппинга внутреннего DAC

## Схема подключения

### Дисплей ILI9341 → ESP32

| Пин ILI9341 | Пин ESP32 |
|-------------|-----------|
| SCK  | GPIO14 |
| MOSI | GPIO13 |
| MISO | GPIO12 |
| DC   | GPIO2  |
| CS   | GPIO15 |
| RST  | (не подключён) |
| VCC  | 3.3V  |
| GND  | GND   |

### Энкодер KY-040 → ESP32

| Пин KY-040 | Пин ESP32 |
|------------|-----------|
| CLK | GPIO22 |
| DT  | GPIO27 |
| SW  | (не используется) |
| +   | 3.3V |
| GND | GND  |

### Звук (внутренний DAC)

| Выход | Пин ESP32 |
|-------|-----------|
| Левый канал | GPIO25 (DAC1) |
| Правый канал | GPIO26 (DAC2) |
| Общий | GND |

Подключите GPIO25 и GPIO26 к усилителю или наушникам через конденсатор 10µF.
