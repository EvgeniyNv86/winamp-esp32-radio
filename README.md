# 🎛️ Winamp Radio на ESP32

Интернет-радиоприёмник в эстетике классического Winamp: металлические панели, зелёный LCD, живой спектроанализатор, бегущая строка с названием трека. Часы по NTP, индикатор WiFi, управление энкодером.

## ✨ Возможности

- **8 радиостанций** с автоматическим определением битрейта и кодека
- **Спектроанализатор** — 24 столбика с градиентом (зелёный → жёлтый → оранжевый → красный) и пик-маркерами
- **Бегущая строка** — название трека из метаданных потока
- **Часы NTP** — синхронизация по WiFi, часовой пояс YEKT-5
- **Индикатор WiFi** — 4 уровня сигнала по RSSI
- **Управление энкодером** — громкость 0–21, переключение станций на краях диапазона
- **Оптимизация отрисовки** — инкрементальное обновление спектра, кэширование текста LCD, минимум SPI-трафика
- **Звук через внутренний ЦАП** ESP32 (I2S DAC, левый канал)

## 🔧 Железо

### Плата: ESP32-2432S028 — Cheap Yellow Display (CYD)

Популярная плата на AliExpress, известная в сообществе как **Cheap Yellow Display (CYD)** — «жёлтая плата». Всё необходимое уже на борту: дисплей, тач, SD-слот, RGB-светодиод, аудиоусилитель. Размер — 86×50 мм, питание 5 В через micro-USB.

| Компонент | Назначение | Контроллер | Шина |
|-----------|-----------|-----------|------|
| 2.8" TFT | Основной дисплей | ILI9341 | SPI (HSPI) |
| Touch | Резистивный тач | XPT2046 | SPI |
| SD-слот | Карта памяти | — | SPI (VSPI) |
| RGB LED | Индикация | — | GPIO 4/16/17 |
| Аудио | Усилитель | — | GPIO 26 (I2S DAC) |

**Характеристики платы:**
- Микроконтроллер: ESP-WROOM-32, двухъядерный, до 240 МГц
- Флеш-память: 4 МБ
- SRAM: 520 КБ
- Разрешение: 240×320, 16-битный цвет (RGB565)
- Подсветка TFT: управляется через GPIO21 (HIGH = включена)
- Питание: 5 В, потребление ~115 мА

### Пины дисплея (используются в проекте)

| Функция | GPIO | Назначение |
|---------|------|-----------|
| TFT_SCK | 14 | Тактовая линия SPI |
| TFT_MOSI | 13 | Данные к дисплею |
| TFT_MISO | 12 | Данные от дисплея |
| TFT_DC | 2 | Data/Command |
| TFT_CS | 15 | Chip Select |
| TFT_BL | 21 | Подсветка |

### Свободные GPIO для энкодера

На плате доступно всего **3 свободных пина** — GPIO 22, GPIO 27 и GPIO 35 (только вход). Энкодер подключается к двум из них:

| Функция | GPIO | Разъём на плате |
|---------|------|-----------------|
| Encoder CLK | 22 | P3 / CN1 |
| Encoder DT | 27 | CN1 |

> ⚠️ **Known issue:** логика энкодера (громкость → переключение станций) в стадии доработки — иногда срабатывает некорректно.

## 🎮 Управление

**Энкодер:**
- Поворот вправо — громкость вверх; на максимуме — следующая станция
- Поворот влево — громкость вниз; на минимуме — предыдущая станция

**Serial-команды (для отладки):**
- `1` — следующая станция
- `2` — предыдущая станция
- `Space` — Play / Stop
- `+` / `-` — громкость

## 📦 Библиотеки

- [**Audio**](https://github.com/earlephilhower/ESP8266Audio) — декодирование MP3, потоковое воспроизведение
- [**LovyanGFX**](https://github.com/lovyan03/LovyanGFX) — быстрый драйвер дисплея с DMA
- **WiFi** — встроенная в ESP32 Arduino Core
- **time.h** — NTP-синхронизация

## 🚀 Установка

### Arduino IDE
1. Установите поддержку ESP32 в Arduino IDE
2. Установите библиотеки **Audio** и **LovyanGFX** через Library Manager
3. Откройте `winamp_radio.ino`
4. Выберите плату **ESP32 Dev Module**
5. Укажите свои WiFi-данные в `ssid` и `pass`
6. Загрузите прошивку

### PlatformIO
```ini
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
lib_deps =
  earlephilhower/ESP8266Audio
  lovyan03/LovyanGFX
monitor_speed = 115200
```

## ⚡ Оптимизации

- **Инкрементальный спектр** — перерисовываются только изменившиеся столбики и пик-маркеры
- **Кэширование LCD** — бегущая строка обновляется только при смене текста, статичная строка — при смене станции/статуса
- **WiFi power-save отключён** — `WiFi.setSleep(false)` для снижения треска в аудио
- **Частота SPI** — 40 МГц запись, 16 МГц чтение
- **Таймеры** — спектр 80 мс, бегущая строка 500 мс, часы 1000 мс
